① 書き込み用の鍵（最初の1回だけ）

鍵はこの端末のブラウザの中だけに保存され、サイトには公開されません。作り方：
  1. GitHub にログインして Fine-grained token の作成ページ を開く
  2. Token name に「GACHIIKU モーター評価」、Expiration は好きな期限
  3. Resource owner を gachiiku にし、Repository access で「Only select repositories」→ gachiiku.github.io を選ぶ
  4. Permissions → Repository permissions → Contents を「Read and write」にする
  5. 「Generate token」で出てきた鍵をコピーして、上の欄に貼り付ける
